Studying Tags

Title Description Remark
Page Title Defines the title of the document shown in the browser's title bar or tab. Must be placed inside the <head> section.
Heading Defines HTML headings from <h1> (most important) to <h6> (least important). Used for SEO and structural hierarchy.
Paragraph Defines a block of text separated by vertical margins. Browsers automatically add space before and after <p> tags.
Links Creates hyperlinks to other web pages, files, or locations within a page. Uses the <a> tag with the "href" attribute.
Images Used to embed visual media in an HTML page. Requires "src" and "alt" (accessibility) attributes.
Formatting Text styling tags like bold, italic, subscript, and highlighted text. Includes <strong>, <em>, <mark>, etc.
Table Organizes data into rows and columns using <tr>, <th>, and <td>. Should be used for tabular data, not page layout.
List Groups related items in ordered (numbered) or unordered (bulleted) formats. Uses <ul> or <ol> as containers for <li> items.
Div, Class, ID Containers used to group elements for styling and layout purposes. Class is for multiple items; ID is for a unique element.
Block & Inline-Block Defines how elements take up space and sit relative to other elements. Block starts on a new line; Inline stays in the flow.
Semantic Layout Defines structural parts of a page. Includes <header>, <nav>, <main>, <footer>, and <section>.
Forms Used to collect user input. Wraps controls like <input>, <textarea>, and <button>.
Input Controls Creates various interactive fields. Attributes like type="text", "checkbox", or "radio" change its function.
Multimedia Embeds audio or video content. Uses <audio> and <video> with <source> tags for compatibility.
Quotes & Citations Defines quoted text from other sources. Uses <blockquote> for long quotes and <q> for short ones.
